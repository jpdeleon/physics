# Physics Video Notes

A pipeline that turns a list of YouTube URLs into a published [Jupyter Book](https://jupyterbook.org/) — one chapter per video, each with **Abstract**, **Key Insights**, **Deep Dive**, and **Video** tabs. Summaries are generated by a local or cloud LLM. The book is automatically built and deployed to GitHub Pages on every push to `main`.

## How It Works

```
settings.yml
    │
    ▼
pipeline/fetch.py        — downloads transcripts via youtube-transcript-api
    │
    ▼
pipeline/summarize.py    — sends transcript to Ollama or Anthropic API
    │                      returns structured JSON (abstract / insights / deep dive)
    ▼
pipeline/render.py       — renders Jinja2 templates → MyST Markdown chapters
    │
    ▼
book/chapters/*.md       — one file per video
    │
    ▼
book/_toc.yml            — auto-generated table of contents
    │
    ▼
jupyter-book build       — produces book/_build/html/
    │
    ▼
GitHub Pages             — served at https://<user>.github.io/<repo>/
```

├── .github/

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
```

### 2. Install uv

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 3. Install Python dependencies

```bash
uv sync
```

### 4. Install the Ollama model (if using the `ollama` backend)

Make sure [Ollama](https://ollama.com/) is installed and running, then pull the model:

```bash
ollama pull qwen3.5
```

## Configuration

All configuration lives in **`settings.yml`**.

### Adding Videos

Add any YouTube URL to the `videos` list. `title_override` is optional.

```yaml
videos:
  - url: https://www.youtube.com/watch?v=VIDEO_ID
    title_override: null

  # Override the title when auto-detection gives a poor result:
  - url: https://www.youtube.com/watch?v=VIDEO_ID
    title_override: "My Custom Chapter Title"
```

Supported URL formats:
- `https://www.youtube.com/watch?v=VIDEO_ID`
- `https://youtu.be/VIDEO_ID`
- `https://www.youtube.com/shorts/VIDEO_ID`

### Choosing a Backend

#### Ollama — local

```yaml
backend: ollama
ollama:
  host: local
  model: qwen3.5:latest
```

Requires Ollama running on `http://localhost:11434`. No API key needed.

#### Ollama — remote server via SSH tunnel

```yaml
backend: ollama
ollama:
  host: jm4          # any hostname defined in ~/.ssh/config
  model: qwen3.5:latest
```

The pipeline automatically opens `ssh -N -L 11434:localhost:11434 jm4` using `/usr/bin/ssh`, which reads `~/.ssh/config` natively — ProxyJump, identity files, and all other SSH config directives are honoured. The tunnel opens before the first summarization call and closes when the pipeline exits.

#### Anthropic

```yaml
backend: anthropic
anthropic:
  model: claude-sonnet-4-6
```

Requires the `ANTHROPIC_API_KEY` environment variable:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

## Running Locally

All commands go through `pipeline.main`:

```bash
uv run python -m pipeline.main [command] [options]
```

### Commands

| Command | Description |
|---------|-------------|
| *(no command)* | Process all videos in `settings.yml`, skip already-rendered chapters |
| `add <url>` | Add a URL to `settings.yml`, fetch + summarize + render it |
| `add <url> --build` | Same as above, then build the book |
| `build` | Build the Jupyter Book HTML |
| `clean` | Remove the build cache |

### Examples

```bash
# Process all videos (skips existing chapters by default)
uv run python -m pipeline.main

# Force reprocess all videos
uv run python -m pipeline.main --no-skip-existing

# Use a different settings file
uv run python -m pipeline.main --settings other.yml

# Add a new video and build in one step
uv run python -m pipeline.main add https://www.youtube.com/watch?v=VIDEO_ID --build

# Build only
uv run python -m pipeline.main build

# Clean build cache
uv run python -m pipeline.main clean

# Open the book locally
open book/_build/html/index.html       # macOS
xdg-open book/_build/html/index.html  # Linux
```

## Deploying to GitHub Pages

### 1. Push to GitHub

```bash
git add .
git commit -m "feat: initial book"
git push origin main
```

### 2. Add the API key secret (Anthropic backend only)

1. Go to your repository → **Settings** → **Secrets and variables** → **Actions**
2. Click **New repository secret**
3. Name: `ANTHROPIC_API_KEY`, Value: your key

> If you use `backend: ollama`, skip this step.

### 3. Enable GitHub Pages

1. Go to **Settings** → **Pages**
2. Set **Source** to `Deploy from a branch`
3. Set **Branch** to `gh-pages` / `/ (root)`
4. Click **Save**

Every push to `main` triggers the workflow automatically. The book will be available at:

```
https://<your-username>.github.io/<your-repo>/
```

> **Note on Ollama in CI:** GitHub Actions runners do not have Ollama installed. The recommended approach is to generate chapters locally, commit `book/chapters/` to the repository, and let CI build the book with `--skip-existing` (already configured in the workflow).

## Chapter Format

Each chapter has four tabs:

| Tab | Content |
|-----|---------|
| **Abstract** | 1–2 paragraph overview |
| **Key Insights** | 4–8 bullet points |
| **Deep Dive** | Core concepts, equations (LaTeX via MathJax), examples |
| **Video** | Thumbnail linking to the original YouTube video |

Videos without an available transcript get a placeholder chapter instead.

## Troubleshooting

### `Could not fetch transcript`

YouTube disables transcripts for some videos (region locks, age gates, private videos). The pipeline generates a placeholder chapter. This is expected behavior.

### `ollama: connection refused`

Ollama is not running. Start it with:

```bash
ollama serve
```

### `ANTHROPIC_API_KEY` not set

```bash
export ANTHROPIC_API_KEY=sk-ant-...
uv run python -m pipeline.main
```

### Re-generating a single chapter

```bash
rm book/chapters/<video_id>.md
uv run python -m pipeline.main
```

### Cleaning stale chapters after removing a video from `settings.yml`

```bash
uv run python -m pipeline.main clean
uv run python -m pipeline.main
uv run python -m pipeline.main build
```
